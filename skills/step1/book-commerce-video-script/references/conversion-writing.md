# 情绪型图书带货写作

## 核心判断

不要先问“这本书有哪些卖点”，先问：

- 哪一类人会在什么时刻需要它？
- 哪种情绪发动机最符合这本书：被理解、好奇、惊叹、希望、野心、怀旧、归属，还是有事实支持的不平？
- 书里的哪句话、哪个故事或哪个解释，能让他突然觉得“原来不是只有我这样”？
- 他买下的不是纸和知识点，而是哪一种变化、陪伴、勇气、解释权或身份认同？

卖点是书有什么，买点是观众为什么此刻想拥有它。正文优先写买点。

## 六段情绪曲线

### 1. 被看见

开头直接进入观众熟悉的瞬间。优先使用：

- 他刚经历过却没说出口的尴尬、委屈或失望；
- 他反复做却始终没有结果的事；
- 一个打破自我安慰的判断；
- “你以为……其实……”背后的真实代价。

不要使用万能问题、空洞大词或与受众无关的奇闻。

### 2. 被说中或被吸引

把主情绪落到一个动作、选择、关系变化、具体冲突或可感知细节。不要复用常见心理文案模板；细节必须从本次受众、原书情境或可以合理观察的生活场景重新生成。

### 3. 情绪拧紧

拧紧不等于制造痛苦。它可以是好奇被吊起、旧理解开始动摇、机会成本被看见、渴望变得清晰，或真实问题的代价逐渐显现。只有原书和目标处境确实支持时，才使用恐惧、愤怒或严重后果。

### 4. 书带来反转

书名在观众已经产生代入后自然出现。只挑一个最有力量的故事、人物、观点或冲突讲透。

知识必须完成情绪作用：

- 替观众命名一种感受；
- 解除一种错误自责；
- 打破一种自我欺骗；
- 给出一种新的理解或选择；
- 让他重新看待自己的过去。

每次强反转必须完成四拍：原书具体细节或判断；它照见观众的哪个动作、关系或选择；它推翻什么旧理解；新理解让观众可以怎样看待或行动。少任一拍，不计为转折。

### 5. 从理解到想拥有

购买理由不是“内容系统、资料丰富、值得一读”。三个购买桥缺一不可：

- **未完价值**：视频交付了什么，书里还有哪两个具体人物、问题、步骤、练习或论证层次；
- **未来使用场景**：买回去后会在什么时刻翻开、重读、查找、练习或送给谁；
- **真实异议回应**：自然回答“太难、太远、已有同类书”等最可能阻止购买的问题。

让观众产生的念头是“我想把它放在手边慢慢读”，而不是“博主让我买”。

### 6. 克制成交

CTA 只做一件事。只有用户明确确认存在商品卡时才说商品卡；未确认时一律建议搜索准确书名或按需购买。

CTA 必须回扣开头的具体场景和准确书名，让行动成为前文的自然收束。不要使用可套到任何书上的推荐句，也不要突然切换成直播间叫卖口吻。

## 文风与节奏

- 像一个认真读过并愿意把关键发现递给观众的人。除非用户提供真实经历，不得声称“我亲历过”“我被治愈了”“这本书改变了我”；真诚来自证据和准确理解。
- 多用“你”“我们”“有时候”，少用“该书”“作者指出”“从某种意义上”。
- 句子长短交替；情绪钉子使用短句，解释部分再舒展开。
- 每 100-160 字至少发生一次变化：场景、追问、反转、刺痛句、安慰、希望或购买理由。
- 抽象概念出现后，下一句必须落到人、动作、关系或选择。
- 允许有立场、有心疼、有愤怒、有遗憾，但不能虚构情绪证据。
- 至少完成一次强反转，并用悬念、证据、故事、反常识、应用场景或情绪变化完成至少 3 次注意力推进。
- 一句只承载一个主要意思；不连续列举三个观点。书面长句拆成“事实句—停顿句—落回观众句”。
- 落盘前默读一遍，凡是一口气难念完或听一遍难理解的句子都改写。

## 需要删除的干稿信号

- 连续两段都在交代背景、年份、概念或作者观点；
- 一段中出现三个以上抽象名词；
- 用“本书讲述了”“作者认为”“这给我们的启示是”推进；
- 只有信息增量，没有观众处境；
- 购买理由可以原封不动套到任何一本书；
- 结尾才第一次出现目标读者；
- 所有段落语气和句长都一样；
- 标题很激烈，正文却没有兑现相同情绪。

## 标题与封面

三套候选分别可以偏向：

1. **刺痛型**：说破一种观众不愿承认的处境；
2. **渴望型**：让人看见自己想成为的样子；
3. **反转型**：推翻一种常见但有代价的理解。

相同下标的发布标题、封面主标题、封面副标题和金句必须表达同一个承诺。不要用正文无法兑现的“震惊”“彻底改变”“所有人必读”。
